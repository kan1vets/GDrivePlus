# ☁ GDrive+ (ver. 1.0)

**GDrive+** — десктопный клиент, проводник и менеджер загрузок для **Google Drive**, написанный на Python (PyQt6). Создан для удобной работы с большими объемами данных без ограничений браузера и принудительной архивации в ZIP.

> 💡 **Быстрый старт:** Скачайте и запустите установщик выше. Программа автоматически установится в систему, создаст ярлыки и будет самостоятельно обновляться при выходе новых версий.

## ✨ Основные фичи

* **Скачивание папок без ZIP-архивов:** полная выгрузка структуры папок по ссылке или напрямую со своего диска.
* **Докачка файлов:** пауза и безопасное возобновление скачивания даже после закрытия программы.
* **Cloud-to-Cloud копирование:** клонирование чужих папок и файлов по ссылке напрямую на свой Google Диск на стороне серверов Google (без скачивания на ПК).
* **Шейпер трафика:** настраиваемое ограничение скорости загрузки (МБ/с).
* **Drag & Drop выгрузка:** перетаскивание локальных файлов и папок из проводника Windows прямо в облако.
* **Умный экспорт:** автоматическое преобразование Google Docs / Sheets / Slides в форматы `.docx`, `.xlsx`, `.pptx`.
* **Калькулятор размера папок:** рекурсивный подсчёт реального веса любой папки на диске.
* **Быстрый шеринг:** открытие доступа по ссылке («Чтение» / «Редактирование») в один клик.

## 🛠 Стек технологий
* **GUI:** PyQt6 (Custom Dark Theme, Frameless Dialogs, RubberBand Selection)
* **API:** Google Drive API v3 (`google-api-python-client`, `google-auth-oauthlib`)
* **Network:** `requests` (Connection Pooling, Stream & Range headers)

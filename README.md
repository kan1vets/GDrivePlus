# ☁ GDrive+ (ver. 1.1)

**GDrive+** — быстрый десктопный клиент, проводник и менеджер загрузок для **Google Диска** и **Яндекс Диска**, написанный на Python (PyQt6). Создан для удобной работы с большими объёмами данных, прямого переноса файлов между облаками и скачивания папок без ограничений браузера и принудительной архивации в ZIP.

[Скачать GDrive+](https://www.google.com/search?q=https://github.com/kan1vets/GDrivePlus/releases/latest/download/GDrivePlus_Setup.exe)

> 💡 **Быстрый старт:** Скачайте и запустите установщик выше. Программа автоматически установится в систему, создаст ярлыки и будет самостоятельно обновляться при выходе новых версий.

## ✨ Основные возможности

* **Два облака в одном окне (Google Диск + Яндекс Диск):** полноценное управление файлами и папками обоих хранилищ с наглядной цветовой индикацией (синий акцент для Google, жёлтый для Яндекса) и точным отображением занятого места.
* **Межоблачное копирование (Cloud to Cloud):** прямой перенос папок и файлов по ссылкам во всех направлениях (`Google ⇄ Яндекс`, `Google → Google`, `Яндекс → Яндекс`) без сохранения на ПК, с отслеживанием прогресса как во вкладке переноса, так и в общем списке «Загрузки».
* **Скачивание папок без ZIP-архивов:** полная выгрузка вложенной структуры папок и файлов по публичным ссылкам или напрямую со своего Google Диска и Яндекс Диска.
* **Докачка и сохранение очереди:** пауза и безопасное возобновление скачивания и выгрузки с места остановки даже после перезапуска программы.
* **Drag & Drop для обоих дисков:** перетаскивание локальных файлов и папок из проводника Windows прямо в текущую директорию или внутрь конкретной папки на Google Диске и Яндекс Диске, а также перемещение объектов между папками внутри облака.
* **Единая умная корзина:** быстрое переключение между корзинами Google Диска и Яндекс Диска, просмотр вложенных папок, выборочное восстановление и асинхронная полная очистка.
* **Мгновенный отклик интерфейса:** асинхронная подгрузка профилей и списков файлов в фоновых потоках с кэшированием в памяти обеспечивает мгновенное переключение между вкладками.
* **Умный экспорт Google Документов:** автоматическое преобразование Google Docs / Sheets / Slides в форматы `.docx`, `.xlsx`, `.pptx` при скачивании и межоблачном переносе.
* **Калькулятор размера папок и быстрый шеринг:** рекурсивный подсчёт реального веса любой папки и создание публичных ссылок с копированием в буфер обмена в один клик.
* **Шейпер трафика:** настраиваемое ограничение скорости загрузки (МБ/с) на лету.

## 🛠 Стек технологий

* **GUI:** PyQt6 (Custom Dark Theme, Frameless Dialogs, Smooth Animations, Drag & Drop)
* **API:** Google Drive API v3 (`google-api-python-client`, `google-auth-oauthlib`), Yandex Disk REST API v1 (`cloud-api.yandex.net`)
* **Network:** `requests` (Connection Pooling, Chunked Streaming, HTTP Range headers, Local OAuth Callback Server)
